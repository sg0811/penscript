# PenScript Website

Responsive static website ready for GitHub Pages.

## Publish on GitHub Pages
1. Create a new GitHub repository (for example `penscript-website`).
2. Upload all files/folders from this package to the repository root.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. GitHub will provide the live URL after deployment.

## Custom domain
When penscript.in is ready, add it under **Settings → Pages → Custom domain**. Follow GitHub's displayed DNS instructions at your domain registrar.

## Replace content later
- Before/after samples are currently HTML placeholders in `index.html` under `#results`.
- Testimonials are placeholders under `#testimonials`.
- Replace those blocks with genuine student samples/testimonials when available.
- Contact details and WhatsApp links are searchable directly in `index.html`.

## Local preview
Double-click `index.html`, or serve the folder with any local web server.
